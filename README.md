# Pratik Poudel — ePortfolio

A responsive, multi-page **static web portfolio and learning resource** presenting my background, web-development learning pages, practical examples, and selected project links.

## Overview

This project began as an academic ePortfolio. It combines profile and education information with learning pages for full-stack development, HTML, CSS, Bootstrap, and JavaScript. The interface includes a glass-inspired visual style, animated background elements, and a light/dark theme.

## Features

- Responsive layouts for desktop, tablet, and mobile
- Home and About pages with profile and education information
- Learning pages for Full Stack Development, HTML, CSS, Bootstrap, and JavaScript
- Practical examples and interactive browser-based demonstrations
- Featured project links
- Light/dark theme
- Scroll progress, reveal effects, and back-to-top control
- Support Me section with eSewa, Khalti, and bank-transfer options
- Keyboard-friendly navigation and descriptive image alternatives where provided

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Introduction, featured content, and Support Me section |
| `about.html` | Developer profile and background |
| `fullstack.html` | Full-stack development concepts |
| `html.html` | HTML concepts and examples |
| `css.html` | CSS concepts and examples |
| `bootstrap.html` | Bootstrap components and responsive layouts |
| `javascript.html` | JavaScript concepts and interactive examples |

## Technology stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5 (Bootstrap learning page)
- Font Awesome
- GitHub Pages

The current project is a static front-end site. Its interactive features run in the browser; no application server or package installation is required.

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/pyatrick666/ePortfolio.git
   cd ePortfolio
   ```
2. Open `index.html` in a browser, or use a local static server such as VS Code Live Server.

## Deployment

The site is hosted with GitHub Pages:

[Open the live ePortfolio](https://pyatrick666.github.io/ePortfolio/)

For updates, push changes to the branch configured as the GitHub Pages publishing source. If the site does not update, check the repository's **Settings → Pages** and **Actions** tabs.
