# Pratik Poudel — ePortfolio

A modern, responsive personal ePortfolio website built to showcase my **skills, coursework, projects, and development journey** as an Information Technology student.

🌐 **Live Website:** https://pyatrick666.github.io/ePortfolio/  
💻 **GitHub Repository:** https://github.com/pyatrick666/ePortfolio

---

## 👋 About the Project

This ePortfolio is designed as a professional digital profile for presenting my academic work, technical skills, projects, and practical learning experience.

The website uses a clean **glassmorphism-inspired interface**, responsive layouts, interactive components, and persistent light/dark mode.

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Glassmorphism UI with animated background
- Light / dark mode with saved preference
- Sticky navigation bar
- Animated page transitions and reveal effects
- Interactive project showcase
- GitHub project integration
- Skills and coursework sections
- Interactive HTML, CSS, JavaScript and Bootstrap demonstrations
- Support Me page with eSewa, Khalti and bank payment options
- Mobile-friendly layouts
- Accessible navigation and interactive controls

---

## 🧰 Technologies

| Technology | Purpose |
