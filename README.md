# Pratik Poudel — ePortfolio

A responsive, multi-page portfolio presenting my academic background, technical skills, coursework, and practical development projects.


## Overview

This project began as an academic ePortfolio and brings together profile information, learning notes, web-development demonstrations, project links, and a Support Me section. The interface uses a glass-inspired visual style, animated background elements, and a persistent light/dark theme.

## Features

- Responsive layouts for desktop, tablet, and mobile
- Home and About pages with profile and education information
- Learning pages for Full Stack Development, HTML, CSS, Bootstrap, and JavaScript
- Practical examples and interactive demonstrations
- Featured project links and GitHub-related content
- Light/dark mode with saved preference
- Scroll progress, reveal effects, and back-to-top control
- Support Me options for eSewa, Khalti, and bank transfer
- Keyboard-friendly navigation controls and descriptive image alternatives where provided

## Technology

- HTML5
- CSS3
- JavaScript
- Bootstrap 5 (on the Bootstrap learning page)
- Font Awesome icons
- GitHub Pages hosting

The site is a static front-end project. Its interactive features run in the browser; no application server is required.

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/pyatrick666/ePortfolio.git
   cd ePortfolio
   ```
2. Open `index.html` in a browser, or use a local static server such as VS Code Live Server for a more realistic local preview.

No package installation or build step is required for the current static version.

## Deployment

The live site is hosted with GitHub Pages:

https://pyatrick666.github.io/ePortfolio/

For changes, commit and push the updated files to the branch configured as the GitHub Pages publishing source, then check the repository's **Settings → Pages** and **Actions** tabs if the live site does not update.
